# Tasks

Тесты пишутся по сценариям спеки `contact-list` и изменённого требования `keep-in-touch`: один тест — один сценарий, ожидаемое — буквально из спеки. Где какой сценарий проверяется — design, решение 6. Каждая задача с кодом — по TDD: тесты названных сценариев → прогон, красный по правильной причине → код → зелёный. e2e на Playwright запускаются только в задачах, где это сказано (`pnpm test:e2e`, перед запуском проверить, не занят ли `:3000` старым сервером).
