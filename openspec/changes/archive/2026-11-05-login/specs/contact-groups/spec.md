# Spec Delta

## MODIFIED Requirements

### Requirement: Готовые группы после выкатки

После выкатки фичи SHALL существовать четыре пустые группы в таком порядке и с такими цветами: «Семья» — розовый, «Друзья» — зелёный, «Знакомые» — жёлтый, «Коллеги» — голубой. Те же четыре пустые группы MUST появляться у каждого нового пользователя при первом входе. Их MUST можно переименовать, перекрасить, переставить и удалить, как созданные пользователем. Существующие контакты после выкатки не состоят ни в одной группе, их данные и заметки не меняются.

#### Scenario: Первый запуск после выкатки
- **WHEN** фича выкачена на базу, где контакты уже есть
- **THEN** в окне «Группы» по порядку — «Семья», «Друзья», «Знакомые», «Коллеги», в каждой 0 человек, цвета — розовый, зелёный, жёлтый, голубой
- **AND** у всех существующих контактов нет групп, их поля и заметки прежние

#### Scenario: Готовую группу можно удалить
- **WHEN** пользователь удаляет группу «Коллеги»
- **THEN** её больше нет ни в фильтре, ни в окне контакта

#### Scenario: Группы нового пользователя
- **WHEN** человек впервые вошёл по ссылке из письма и открыл окно «Группы»
- **THEN** там по порядку — «Семья», «Друзья», «Знакомые», «Коллеги», в каждой 0 человек, цвета — розовый, зелёный, жёлтый, голубой

#### Scenario: Удаление у одного не трогает другого
- **WHEN** пользователь A удалил свою группу «Коллеги», а пользователь B открыл окно «Группы»
- **THEN** у B группа «Коллеги» на месте

### Requirement: Название группы

Название группы MUST быть непустым после обрезки пробелов по краям и не длиннее 40 символов. Две группы одного пользователя MUST NOT называться одинаково без учёта регистра и разницы «ё» и «е»; у разных пользователей названия могут совпадать. При нарушении группа не сохраняется, а под полем — понятная ошибка.

#### Scenario: Пустое название
- **WHEN** пользователь пытается создать группу с названием из одних пробелов
- **THEN** группа не создаётся, под полем ошибка «Укажите название»

#### Scenario: Слишком длинное название
- **WHEN** пользователь вводит название из 41 символа
- **THEN** группа не сохраняется, под полем ошибка «Слишком длинно — до 40 символов»

#### Scenario: Такая группа уже есть
- **WHEN** группа «Теннис» есть, и пользователь создаёт или переименовывает другую группу в «теннис»
- **THEN** группа не сохраняется, под полем ошибка «Такая группа уже есть»

#### Scenario: Пробелы по краям
- **WHEN** пользователь создаёт группу «  Теннис  »
- **THEN** группа называется «Теннис»

#### Scenario: Такое же название у другого пользователя
- **WHEN** у пользователя A есть группа «Теннис», и пользователь B создаёт группу «Теннис»
- **THEN** группа у B создаётся без ошибки
